# Learn JavaScript and Playwright 4x

A hands-on learning workspace for JavaScript fundamentals and QA automation concepts. The repository is organized into chapters, with small JavaScript examples and Markdown notes that can be explored independently.

## Chapters

| Folder | Topics |
| --- | --- |
| [`00_Chapter_Prompt_Eng/`](./00_Chapter_Prompt_Eng/) | Prompt engineering for QA, RICE-POT, and anti-hallucination guidance |
| [`01_Chapter_JS_Basics/`](./01_Chapter_JS_Basics/) | First JavaScript programs and basic math |
| [`02_Chapter_JS_Keywords_Identifiers/`](./02_Chapter_JS_Keywords_Identifiers/) | JavaScript keywords, identifiers, comments, and how a JavaScript engine works |
| [`03_Chatper_JS_Literals/`](./03_Chatper_JS_Literals/) | Literals, numbers, `null`, `undefined`, and special numeric values |
| [`04_Chapter_Operators/`](./04_Chapter_Operators/) | Arithmetic, assignment, comparison, and logical operators |

## Getting started

1. Install [Node.js](https://nodejs.org/).
2. Clone this repository and open it in your editor.
3. Run an example from the repository root:

   ```bash
   node 01_Chapter_JS_Basics/01_HelloWord.js
   ```

The examples are standalone learning exercises; no package installation or build step is required. Run other `.js` files by replacing the path with the file you want to explore. Read the Markdown notes in each chapter for additional explanations.

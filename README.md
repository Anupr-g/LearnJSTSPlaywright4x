## Getting started

1. Install [Node.js](https://nodejs.org/).
2. Clone this repository and open it in your editor.
3. Run an example from the repository root:

   ```bash
   node 01_Chapter_JS_Basics/01_HelloWord.js
   ```

The examples are standalone learning exercises; no package installation or build step is required. Run other `.js` files by replacing the path with the file you want to explore. Read the Markdown notes in each chapter for additional explanations.
